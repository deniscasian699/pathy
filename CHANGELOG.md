# Changelog

All notable changes to PATHY will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

---

## [Unreleased]

### Added
- Google AdMob adaptive banner, native, interstitial and app-open advertising
- Google UMP consent flow and advertising privacy choices in Settings
- Supporter and Monthly Supporter ad-removal entitlement handling
- Multiple visits per country with individual dates, cities or areas
- Country-specific city suggestions from the local GeoNames dataset
- Themed visit-entry and visit-action dialogs
- Modern and legacy widget previews using the real country geometry

### Changed
- Premium Lifetime unlocks premium features and still includes advertising
- Interstitial progress is retained between sessions and display is triggered by navigation
- Persistent banner ownership reduces repeated requests during tab changes
- Ad request pacing and backoff handling
- Map zoom, panning, country-label visibility and maximum zoom
- System-bar insets for edge-to-edge layouts

---

## Existing Features
- Country tracking, interactive map, continent statistics and achievements
- Personal travel timeline
- Premium Lifetime travel notes, custom map themes and eligible app icons
- Resizable home-screen map widget
- Local travel storage without a PATHY account or GPS tracking
